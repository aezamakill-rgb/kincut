# KinCut — สตูดิโอตัดต่อในกระเป๋า

แอปตัดต่อวิดีโอ/แต่งภาพสำหรับคอนเทนต์สั้น ประมวลผลในเครื่องของคุณเอง ไม่อัปโหลดไฟล์

เปิดใช้: https://aezamakill-rgb.github.io/kincut/
- Android / Windows / Mac: เปิดใน Chrome หรือ Edge → เมนู → ติดตั้งแอป
- iPhone / iPad: เปิดใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม

repo นี้มีเฉพาะไฟล์แอปที่ build แล้ว (สร้างโดยทีม AI "สามแรง": Claude · GPT · Gemini)
ฟอนต์ไทย: SIL OFL · สติกเกอร์: Google Noto Emoji (Apache-2.0) — ดูไฟล์ลิขสิทธิ์ใน fonts/ และ stickers/
